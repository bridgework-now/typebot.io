With the NocoDB block, you can create, update or get data from your NocoDB tables.

All actions use NocoDB API v3 and require both a `Base ID` and a `Table ID`. When upgrading an existing block, enter its `Base ID` in each action before running it. You can find both IDs in the URL when you open the table; see [NocoDB's guide to finding IDs](https://nocodb.com/docs/apis/ids). The Base URL in your account settings continues to support self-hosted instances.

Search and update actions retrieve up to 1000 matching records. Linked fields returned by searches retain the v3 nested record format (`id` and `fields`); ordinary fields and primary key fields remain available by name for response mapping. Relation updates append links without removing existing links.

## How to find my `Table ID`?

To find your `Table ID`, you need to go to your NocoDB dashboard and click on the 3 dots button next to your table name.

## Search Records

This action allows you to search for existing records in a table. It requires your `Table ID` and can optionally take a `View ID` to search in a specific view.

<Frame>
  <img
    src="/images/blocks/integrations/nocodb.jpg"
    alt="NocoDB block example"
  />
</Frame>

You can configure the filter to return `All`, `First`, `Last` or `Random` found records.

Then all you need to do is to map the found fields to variables that you can re-use on your bot.
